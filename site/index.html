Guide

Text2Prod

Text2Prod is a plugin of skills for coding agents: Claude Code, Codex (CLI and App), and OpenCode. A bootstrap skill, zed-mode, makes the agent check for a matching skill before it replies. Feature work leaves a spec, a plan, and a review in your repository.

The shadow runs first

When you send a prompt, zed-mode sends a shadow ahead of the work. The shadow matches your request to a playbook and copies the playbook's steps into a todo list. The real work follows where those steps land, and each step calls the skill it names.

flowchart LR
  P["Your prompt"] --> Z["zed-mode"]
  Z -->|matches| B["One of 23 playbooks"]
  B -->|copies steps into| T["Todo list"]
  T -->|each step calls| S["Skills"]
  S --> E["Evidence you can check"]

If you only remember one thing

Give the agent a goal and a way to check it. Copy this prompt and swap in your own problem:

/text2prod:zed-mode use the bug-fix playbook. the nightly export skips the last page of results. reproduce it first, then fix it. done means the three-page fixture exports every row.

The prompt names the playbook, says what to do first, and gives a done check that can fail. Naming the playbook is the part that matters. In the release evals, on a plain bug report no session produced the bug-fix playbook's step list on its own (0 of 3, with or without the plugin), so naming the playbook is the reliable path. Chapter 2 shows how.
