Set up

Install Text2Prod once for each harness you use, then ask one routing question to confirm the bootstrap loaded.

Install

Claude Code

Run these two commands in a Claude Code session, then start a new session so the session-start hook runs.

/plugin marketplace add phuongddx/text2prod
/plugin install text2prod@text2prod

Codex CLI

Text2Prod is not in the official Codex plugin marketplace yet. Add this repository as a Git marketplace, then install the plugin.

codex plugin marketplace add https://github.com/phuongddx/text2prod.git
codex plugin add text2prod@text2prod

Codex App

Build an archive with scripts/package-codex-plugin.sh and upload it through the Codex portal. The script needs a prior official package as its metadata seed.

OpenCode

Text2Prod supports OpenCode V2. Add the plugin from the command line:

opencode plugin add github:phuongddx/text2prod

You can also add "github:phuongddx/text2prod" to the plugins array in opencode.json.

How the bootstrap loads

The bootstrap is the zed-mode skill. It carries the skill-first rule, the playbook table, and the autonomy rules. Each harness gets it into the session a different way.

HarnessHow zed-mode loads
Claude Codehooks/hooks.json runs hooks/session-start on startup, on /clear, and on compaction. The hook injects zed-mode into the session.
OpenCodeThe plugin injects the bootstrap through the context session hook on every model call.
CodexCodex has no session-start hook. It finds the skills on its own, and the agent loads zed-mode by its description like any other skill.

Check that it loaded

Ask a routing question and tell the agent not to start. A working install answers by naming a playbook before it does anything else.

/text2prod:zed-mode which playbook would you use to fix a flaky test? answer only, don't start.

A working answer names the bug-fix playbook and the skills its steps call, such as systematic-debugging and test-driven-development. It does not touch any file.

If the agent answers without naming a playbook, start a new session, or run /clear on Claude Code, which runs the session-start hook again. On Claude Code also check that the plugin is enabled. On Codex there is no hook, so name the skill in your request.
